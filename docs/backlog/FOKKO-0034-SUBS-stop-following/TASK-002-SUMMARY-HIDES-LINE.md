# FOKKO-0034-SUBS/TASK-002 · El resumen no muestra la línea oculta
Feature: `internal/subscriptions/domain`

Como usuario quiero que una línea oculta no vuelva, para no tener que repetirlo.

## Criterios
- Dada una línea oculta, cuando se arma el resumen, entonces no aparece ni suma al total.
- Dada una línea oculta que recibe un cobro nuevo en la cartola siguiente, cuando se arma el resumen, entonces sigue oculta.

## Fuera
- Nada.

## Notas
- Ninguna.
