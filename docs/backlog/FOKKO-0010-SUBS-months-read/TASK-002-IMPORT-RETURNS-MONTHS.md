# FOKKO-0010-SUBS/TASK-002 · `ImportStatement` devuelve los meses
Feature: `internal/statements/usecases`

Como usuario quiero ver los meses leídos al terminar la subida, para saber qué período cubre.

## Criterios
- Dada una cartola con cargos de dos meses, cuando se importa, entonces el resultado trae esos dos meses.
- Dada una importación rechazada, cuando falla, entonces no hay resultado ni meses.
