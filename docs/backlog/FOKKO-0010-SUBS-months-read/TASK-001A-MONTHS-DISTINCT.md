Feature: `internal/statements/domain`



## Criterios
- Dados cargos de agosto y septiembre, cuando se piden los meses, entonces devuelve agosto y septiembre en orden.
- Dados varios cargos del mismo mes, cuando se piden los meses, entonces ese mes aparece una sola vez.
- Dados cero cargos, cuando se piden los meses, entonces devuelve una lista vacía.
